# 🎨 Sistema de Identidad Visual y Activos Gráficos - KILLAgent

Este directorio aloja los activos visuales oficiales de **KILLAgent**, integrados con el sistema de renderizado adaptativo de la aplicación.

---

## 📂 Directorios y Nomenclatura Corporativa

```text
src/main/resources/assets/
├── icons/
│   ├── app-icon.ico               # Icono multi-resolución Windows para instalador y ejecutable
│   ├── app-icon.png / .svg        # Icono maestro de la aplicación (Luna creciente + Estrella)
│   ├── tray-no-reader.svg/.png    # Estado Tray: Sin lector de tarjeta
│   ├── tray-no-card.svg/.png      # Estado Tray: Lector conectado, esperando DNIe
│   ├── tray-card-ready.svg/.png   # Estado Tray: DNIe verificado y listo
│   └── tray-busy.svg/.png         # Estado Tray: Firma / Ingreso de PIN en curso
├── images/
│   ├── brand-logo.svg / .png      # Logo tipográfico 'CH'ASKA' con degradado neón
│   ├── chaska-wordmark.png        # Wordmark institucional oficial
│   ├── chaska-star-emblem.png     # Isotipo de la Estrella Ch'aska de 8 puntas
│   └── shield-badge.svg / .png    # Sello visual de seguridad para el modal de firma
└── mockups/
    └── .gitkeep                   # Espacio para especificaciones de diseño y Figma exports
```
